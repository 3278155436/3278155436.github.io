GitHub Pages 部署完全指南

2026-10-24 · 约 5 分钟阅读

GitHub Pages 是 GitHub 提供的免费静态网站托管服务。只要你有一个 GitHub 账号，就能把任意静态网站（HTML/CSS/JS）发布到互联网上，无需购买服务器、无需配置环境。

第一步：创建仓库

登录 GitHub 后，点击右上角 + → New repository，创建一个新仓库：

  • 仓库名设置为 你的用户名.github.io（这是个人/组织站点，直接绑定根域名）
  • 可见性选择 Public
  • 勾选 Add a README file 初始化仓库
💡 如果仓库名不是 用户名.github.io 也可以，网站会发布在 用户名.github.io/仓库名 子路径下，这就是「项目站点」。

第二步：上传网站文件

把网站文件推送到仓库。最简单的方式是在仓库页面点击 Add file → Upload files，直接把 index.html、css/ 等文件拖进去。也可以使用 Git 命令行：

git clone https://github.com/你的用户名/你的用户名.github.io.git
cd 你的用户名.github.io

# 把网站文件复制进来后：
git add .
git commit -m "feat: 发布博客首版"
git push origin main

第三步：开启 Pages

  1. 进入仓库的 Settings → Pages
  2. 在 Build and deployment 下，Source 选择 Deploy from a branch
  3. Branch 选择 main、目录选择 / (root)，点击 Save

等待 1～2 分钟，访问 https://你的用户名.github.io 即可看到你的网站上线。

第四步（可选）：绑定自定义域名

如果你有自己的域名，可以在域名服务商添加一条 CNAME 记录指向 你的用户名.github.io，然后在仓库根目录添加一个 CNAME 文件（内容为你的域名），并在 Settings → Pages 中填入域名。GitHub 会自动为你的站点签发 HTTPS 证书。

常见问题

页面显示 404？

检查根目录是否存在 index.html（注意文件名全小写），以及 Pages 是否已成功部署（可在仓库的 Actions 标签页查看部署状态）。

样式没加载？

项目站点的资源路径要使用相对路径（如 css/style.css），不要以 / 开头，否则会指向域名根目录导致 404。

更新后没生效？

浏览器缓存了旧页面，强制刷新（Ctrl+F5）或等待几分钟即可。

进阶方向

  • Jekyll / Hugo / Hexo：静态站点生成器，用 Markdown 写文章，自动生成整站
  • GitHub Actions：配置自动构建，push 后自动发布
  • 评论系统：接入 Giscus（基于 GitHub Discussions）实现免费评论
