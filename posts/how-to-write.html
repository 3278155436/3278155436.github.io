如何给这个博客添加新文章

2026-10-20 · 约 3 分钟阅读

本博客是纯静态站点，发布新文章只需要三个步骤，全程无需数据库和后端。

第一步：复制文章模板

在 posts/ 目录下复制任意一篇现有文章（例如 hello-world.html），重命名为你的新文章，例如 my-new-post.html。建议使用英文小写加连字符的文件名。

第二步：修改内容

打开新文件，修改以下几处：

  • <title> —— 文章标题（显示在浏览器标签页）
  • <h1> —— 文章大标题
  • post-meta —— 发布日期和分类标签
  • <article> 内的正文 —— 用 <h2>、<p>、<pre>、<blockquote> 等标签组织内容，样式已全部内置

第三步：更新首页列表并推送

打开 index.html，在文章列表最上方按相同结构添加一个 <li class="post-item"> 条目，然后提交推送：

git add .
git commit -m "post: 新文章《我的新文章》"
git push

推送后 GitHub Pages 会自动重新部署，1～2 分钟后文章即上线。

💡 小技巧：图片统一放在 images/ 目录，引用时使用相对路径 ../images/xxx.png（相对于 posts 目录）。
